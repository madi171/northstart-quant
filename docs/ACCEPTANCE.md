# 验收清单与验证状态

## 当前状态

本次只进行了源码检查与文件交付检查，**未运行构建、编译、测试、类型检查、lint、HTTP 服务或浏览器联调**。测试代码是待执行资产，不代表测试已通过。当前没有已部署的演示地址。

## 已提供的自动化测试

在自己的开发环境安装依赖后执行：

```bash
PYTHONPATH=backend python -m pytest backend/tests -q
npm run build
```

覆盖行为：

- 策略不能导入模块、访问属性、调用危险函数、无限循环或使用乘幂。
- 非法目标仓位被拒绝；零仓位保持初始资金。
- 收盘信号只能在下一根行情成交。
- 改动未来行情不改变历史净值和历史成交。
- 演示数据不因查询区间变化而改变同日价格。
- 真实数据不可降级到演示数据。
- 重复行情日期被拒绝；交易成本降低收益。
- 重复确认不重复成交；紧急停止、撤销策略、过期审批、账户版本变化均阻止成交。
- 任务请求幂等，不能用同一幂等键改变参数。
- 明文模型密钥、非 HTTPS 模型地址、非法环境变量引用被拒绝。
- 历史回放不能作用于在线模拟账户。
- 签名 token 被修改后认证失败。

测试强制使用进程内 SQLite，不读取部署数据库。尚未覆盖 PostgreSQL 真实并发、网络故障注入、进程崩溃恢复与浏览器行为。

## 人工端到端验收

| 操作 | 预期 |
|---|---|
| 不配置密码启动 API | 拒绝启动，无默认弱口令 |
| 登录后首次进入 | 标的池为空；演示策略、演示行情和演示研究器明确标记 |
| 添加一个自选标的 | 代码、市场、币种、每手数量正确；刷新页面后仍存在 |
| 重复添加同代码 | 返回冲突，不新增重复标的 |
| 创建一年演示回测 | queued → running → succeeded，页面自动刷新 |
| 查看回测详情 | 曲线、指标、交易列表、数据哈希与来源一致 |
| 导出清单再脚本重放 | 数据快照相同，指标一致；篡改快照后明确失败 |
| 用缺失的真实数据源回测 | 明确失败，不能显示演示收益冒充真实数据 |
| 批准无评估策略 | 被拒绝 |
| 完成回测后批准策略 | 可用于在线模拟信号 |
| 生成信号并人工确认 | 仅对应模式与币种的模拟账户变化 |
| 重复确认相同订单 | 不重复扣款或增加持仓 |
| 打开紧急停止后确认旧订单 | 被拒绝 |
| 取消运行中的研究任务 | 后续不产生候选策略或模拟订单 |
| 选择两个模型研究 | 保留各自提案与失败原因；候选不自动发布 |
| 修改策略后保存 | 创建新版本，原版本不被覆盖 |
| 切换 demo/live | 持仓和资金互不串用；前端持续标记模拟交易 |
| 开启定时任务 | 同一日/周只入队一次；版本切换从后续周期开始 |
| 请求真实订单接口 | 返回409，任何配置均不能绕过 |
| 备份并在隔离环境恢复 | 记录完整，快照哈希一致，先核对再开放操作 |
