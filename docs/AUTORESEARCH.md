# 策略自主研究与多源特征

在「策略工作台 → 策略自主研究」页面选择策略、标的和行情区间，设置交易风格、收益目标、风险约束和预算后提交。也可从已完成的回测／研究主策略实验开始，沿用冻结行情、外部特征、日期、资金、费用、滑点及仓位上限。

## 每轮实验如何运行

1. 模型基于当前保留版本、既往诊断和可见数据提出一个可证伪假设。
2. 生成受限 Python 策略或参数的最小修改。默认最多修改12行代码、3个参数；超预算计为失败轮次，不执行候选回测。
3. 固定行情、执行规则和目标：按时间60%训练、20%调优验证、20%最终测试。每段从现金开始，使用过去价格预热。
4. 输出收益、回撤、夏普、成交笔数、换手及信号诊断；记录相对父版本的指标变化。训练／验证长度不同，收益差异只能作为诊断线索。
5. 候选必须满足回撤、换手、最低成交约束；优先替换不合规版本，否则按验证目标、再按夏普排序，严格改善才保留。其他情况回滚到此前保留版本，后续从该版本继续。原始策略始终保留。
6. 保存假设、代码差异、参数变化、评估指标、决定及原因、模型用量、协议与数据指纹。回滚候选仍以未批准版本归档，不作为下一轮起点。
7. 未达到目标则依据诊断继续；达到目标、耗尽轮数／时间预算或模型访问受限则停止。最终选定版本在独立测试区间评估，测试结果不反馈模型，也不据此重新选优。

这是策略候选优化，不会自动修改后端引擎、放宽规则、批准策略或交易。反复查看同一测试区间后重新发起实验会破坏独立性；历史模型知识也可能泄漏，真正的未来模拟观察仍然必要。

## 可选交易风格

| 风格 | 固定执行节奏 | 研究方向 |
| --- | --- | --- |
| 均衡日线 | 每个交易日可调仓 | 平衡收益、风险与换手 |
| 长线趋势 | 每20根日线可调仓 | 60–250日趋势、财报及宏观过滤 |
| 短线波段 | 每5根日线可调仓 | 5–30日动量、反转、量价过滤 |

调仓节奏在引擎中执行，基线和候选一致；建议窗口由模型使用，不保证持仓时长。信号在收盘产生，之后符合调仓节奏的交易日开盘撮合。区间切分沿用全区间调仓相位。当前是日线研究，不支持分钟／逐笔策略，也没有盘口排队、市场冲击或成交容量模型。

## 多源数据输入

| 类别 | 可以提供的数值特征 | 当前接入方式 |
| --- | --- | --- |
| 价格／量价 | OHLCV、指数、汇率、价差 | 当前标的OHLCV内置；其他序列导入JSON |
| 财报 | ROE、盈利增速、估值、现金流 | 已授权的历史可得版本JSON |
| 宏观 | 利率、通胀、信用、经济状态 | 带发布时间和历史版本的JSON |
| 盘口 | 价差、深度、买卖盘失衡 | 预先聚合为日级数值因子 |
| 公告／新闻 | 事件标记、情绪、影响分数 | 预先转为数值并注明实际可用时间 |
| 其他 | 行业、资金流、情绪等 | 相同的时间快照协议 |

目前没有新增自动财报／宏观／盘口供应商订阅。使用页面的JSON文件导入或输入框，最多5000条、64个字段。示例见 [RESEARCH_FEATURES.example.json](RESEARCH_FEATURES.example.json)，其中数值仅用于说明格式。

每条记录包含 `name`、`category`、`symbol`、`observed_at`、`available_at`、`value`、`source`、`max_age_days`。标的必须匹配实验；宏观公共因子可用 `symbol="*"`。同名特征须保持来源、类别、标的、有效期一致。更换来源需要更换字段名。

- `observed_at` 是观测／所属期间的时间，例如财报期末，不代表当时已公布。
- `available_at` 应为首次公开发布与研究系统首次实际获取两者的较晚时间。修订值另存新的可用时间，不可覆盖旧版本或使用今天的重述值回填历史。
- 时间必须带时区。保守规则：仅在 `available_at` **严格早于该交易日UTC零点**时可见；因此当日公告不会影响当日信号。
- 同一字段优先取最新观测期间，再取当时可用的最新修订；延迟发布的旧期间修订不会替换更新期间。超过实际可用时间后 `max_age_days` 的值视为缺失。
- 策略读取 `feature("fundamental.roe", 0)`，第二个参数是显式缺失默认值。内置字段为 `price.open/high/low/close/volume`；在当日收盘时可知。字段当前值可用于过滤，历史滚动因子需事先按可得时间计算。

例如仅在财报因子有效时允许趋势仓位：

```python
def target(history, params):
    if len(history) < params["slow"]:
        return 0.0
    if feature("fundamental.roe", 0) <= params["min_roe"]:
        return 0.0
    if mean(history[-params["fast"]:]) > mean(history[-params["slow"]:]):
        return params["weight"]
    return 0.0
```

参数示例：`{"fast":20,"slow":120,"min_roe":0.1,"weight":0.2}`。缺失默认值应按因子语义设计，不可把缺失误判为利好。上传者须核实时间、授权、单位及质量；结构校验与指纹不证明数据真实。历史模式的调优区间因子预览和来源信息会发送给所选外部模型，最终测试区间的发布记录不会发送。

## 实验归档与复现

报告支持导出实验JSON日志和最终策略复现清单。清单包含最终选择的代码、参数、特征快照、固定调仓节奏与行情指纹；将原 `DATA_DIR` 行情快照一起保留，再执行：

```bash
PYTHONPATH=backend python -m app.cli --manifest replay-任务ID.json --out data/replay.json
```

复现只运行离线回测，不再次调用模型；行情或外部特征指纹不一致会拒绝运行。后续回测保存的候选版本会继承其特征和调仓规则。多源外部特征或非每日调仓策略目前限离线研究，在线信号明确拒绝；上线前仍需实现新鲜数据接入和调仓日历。最终候选可在完成任务和独立测试后人工批准，批准本身不替换调度策略。
